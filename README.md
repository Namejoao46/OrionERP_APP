# OrionERP_APP

## Requisitos

- Docker Desktop

## Executar

git clone https://github.com/Namejoao46/OrionERP_APP.git

cd OrionERP_APP

docker compose up --build

Frontend:
http://localhost:8081

Backend:
http://localhost:8080
